# Global Rules

- Read `AGENTS.md` and relevant docs/rules/skills before work.
- Modify only files necessary for the requested task.
- Avoid unrelated refactors and unnecessary dependencies.
- Reuse existing implementations when they meet requirements.
- Prefer clear, explicit code over clever abstractions.
- Never commit secrets or real student/biometric data.
- Validate external input; fail safely and clearly.
- Add tests for changed business behavior.
- Update documentation and task status when appropriate.
- Report what changed and which checks were actually run.
