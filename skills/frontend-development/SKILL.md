# Skill: Frontend Development

## Required context
Read PRD, architecture, frontend plan, and frontend/architecture rules.

## Procedure
1. Inspect current routes/components and reuse existing patterns.
2. Identify Server vs Client Component needs.
3. Keep route files thin; implement feature components/hooks/services.
4. Use shared API client and runtime validation for untrusted data.
5. Implement loading, empty, error, and success states.
6. Test keyboard behavior, responsive layout, and reduced motion.
7. Run type-check/lint/tests and report actual results.

## Constraints
Do not add dependencies or refactor unrelated modules without justification.
