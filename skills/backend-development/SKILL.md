# Skill: Backend Development

## Required context
Read PRD, architecture, API spec, security rules, and backend plan.

## Procedure
1. Inspect existing module patterns.
2. Define validation and authorization requirements.
3. Implement route, controller, and service responsibilities.
4. Use Prisma through backend services.
5. Add consistent errors and audit behavior where needed.
6. Add unit/integration tests for success, invalid input, and denied access.
7. Update API documentation.

## Constraints
Never trust client identity claims; do not bypass service or authorization rules.
