# Skill: Code Review

## Review order
1. Correctness against PRD and acceptance criteria.
2. Authorization and privacy risks.
3. Attendance integrity and database constraints.
4. Error handling and edge cases.
5. Architecture boundaries and duplication.
6. Type safety and test coverage.
7. Performance and accessibility.
8. Documentation updates.

## Output
List findings by severity with file/line references where available. Distinguish confirmed defects from suggestions. Do not request unrelated refactoring.
