# Skill: UI/UX Development

## Required context
Read PRD, frontend plan, and frontend rules.

## Procedure
1. Identify the user and task priority for the screen.
2. Reuse the design tokens, shared components, and existing page layout.
3. Keep forms and data tables accessible and responsive.
4. Provide loading, empty, error, success, and permission states.
5. Use React Bits only where it supports the task; respect reduced motion.
6. Verify keyboard navigation and color contrast.
7. Avoid decorative effects that obscure attendance data.

## Constraints
Do not redesign unrelated pages as part of a focused feature task.
