# Skill: Testing and QA

## Procedure
1. Map the change to acceptance criteria.
2. Identify positive, negative, permission, and edge cases.
3. Add or update unit and integration tests.
4. Test database constraints and transactions for data integrity changes.
5. Run relevant tests, lint, and type checks.
6. Report exact commands and outcomes; state skipped checks.
7. Record any remaining risks.

## Priority cases
Authentication/authorization, duplicate attendance, unknown/ambiguous recognition, invalid session, class membership, report calculations, and biometric deletion.
